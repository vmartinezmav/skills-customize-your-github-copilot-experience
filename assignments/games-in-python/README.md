
# 📘 Assignment: Hangman Game

## 🎯 Objective

Build a word-guessing game using Python strings, loops, conditionals, random selection, and user input.

## 📝 Tasks

### 🛠️ Build the Guessing Game

#### Description
Create a Hangman game that selects a hidden word and lets the player guess its letters.

#### Requirements
Completed program should:

- Randomly select a word from a predefined list.
- Accept letter guesses and show guessed letters in the word, displaying unguessed letters as underscores (for example, `_ _ _`).
- Track incorrect guesses and the number of attempts remaining.

### 🛠️ Complete the Game Flow

#### Description
Continue the game until the player guesses the word or runs out of attempts, then report the outcome.

#### Requirements
Completed program should:

- Allow the player to keep guessing while attempts remain and the word is not yet solved.
- End the game when the word is guessed or attempts are exhausted.
- Display a win message for a correctly guessed word and a lose message when attempts run out.
